# agentic-playground
A hands-on playground for learning, experimenting with, and building autonomous LLM agents and multi-agent workflows.


the Entire Agent Foundation:Tools: Deterministic Python functions wrapped with type hints and descriptive docstrings.The Schema: How Ollama converts docstrings into tool definitions for the LLM.The Dispatcher (TOOL_MAP): Translating the model's text decision into actual Python execution.The ReAct Cycle: Thought $\rightarrow$ Tool Call $\rightarrow$ Tool Output in messages $\rightarrow$ Final Synthesis.State / Memory: Persisting observations to disk and retrieving them on demand.
